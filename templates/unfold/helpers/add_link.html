{% comment %} Overrides unfold/helpers/add_link.html. Unfold ships this as a 38px circle containing nothing but a "+", with the action hidden in a `title` attribute. A round icon button is for something whose meaning is obvious from its shape — this one is the primary action on the page, and it was the only control that made you hover to find out what it did, or guess. So: an ordinary button, with the "+" kept and the name of the thing beside it. The label comes from the model's own `verbose_name` (`capfirst`, not `title`, so "API credential" keeps its capitals instead of becoming "Api Credential"), which means it reads correctly for every model without any per-model configuration.
