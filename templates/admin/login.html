{% extends 'unfold/layouts/unauthenticated.html' %} {% comment %} Overrides unfold/templates/admin/login.html. Same change as registration/logged_out.html, and for the same reason: Unfold leaves the form loose on a white page, while everything else in this admin puts a self-contained block of content on a surface card. A sign-in form is the most self-contained block there is. Everything the page is FOR goes inside the card — the title, any error messages, both fields and both buttons. Errors especially: a validation message floating outside the card would read as belonging to the page rather than to the form that produced it. The heading and the line under it are written here rather than through unfold/helpers/unauthenticated_title.html. That include renders a title and a subtitle with a rule beneath, and leaves nowhere for a sentence to sit that still belongs to the heading — it would land under the rule, next to the form instead of with the title. Writing the two lines directly also makes this card and the signed-out card the same shape: mark, heading, one line, action. One fewer Unfold include to depend on, as a side effect. The mark is the same partial the marketing site and every allauth page include, so there is one drawing of it rather than a second that drifts. It needs --accent / --on-accent, which are site tokens the admin does not emit; the stylesheet maps them onto the rail's colours for this one element, so the mark here is the mark on the rail you see once you are in. The inputs are not styled here. `.pf-auth-card` is named alongside `#main` in the stylesheet's field rules, so these fields get the same inset wells and the same accent focus halo as every field in the admin, from one rule rather than a copy that can drift. Kept from Unfold: the layout, the message includes, `unfold/helpers/field.html` (which renders the label, widget and errors together), and the button component — so the accent still follows a retheme. The form action, method and id are unchanged; `login-form` is referenced by Unfold's own scripts. {% endcomment %} {% load i18n unfold %} {% block extrastyle %} {{ block.super }} {{ form.media }} {% endblock %} {% block title %} {{ title }} | {{ site_title }} {% endblock %} {% block content %}
