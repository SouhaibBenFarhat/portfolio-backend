{% comment %} The hirees.me mark: a lowercase "h" closed by the full stop of ".me", on a petrol tile. Included by every server-rendered page that shows the wordmark — templates/site_base.html (and so every allauth page through it), core/templates/core/landing.html, and templates/socialaccount/signup.html, which sits outside the shell but can still include this. A filled tile rather than bare strokes, deliberately: a naked "h" beside the word "hirees" stutters, because the eye reads it as a letter and starts the name twice. A tile reads as an object. The fills are tokens, so it follows the theme; size comes from `.logo`, which each page defines. THE OTHER COPY: core/views.py draws the same letter for /favicon.svg and /favicon-full.svg.
