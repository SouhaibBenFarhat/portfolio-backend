Split out of partials/_fields.html so a single field can be placed by hand (a page with no Django form object behind it, or a field that sits apart from the rest), and so the variant below is defined in exactly one place instead of being re-decided per page. `variant` picks the field's plane. It is about affordance, not depth: (unset) The field sits on the page, so it sinks into a well. Recessed against the page around it, that reads as "type here". on-surface The field sits on an elevated surface — a card, a panel. It rises to the writable plane instead of sinking, because on a card the recessed fill is the same grey a disabled control is drawn in, and a field nobody can distinguish from a disabled one is a bug, not a style. Elevation is for containers; a control's plane is chosen for what it affords. Named for where the field is, not for how it ends up looking, so the call site states a fact it actually knows and the stylesheet stays free to change what that fact means.
